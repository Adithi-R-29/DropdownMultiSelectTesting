# Dropdown and Multi-Select Lists — Selenium Automation

## Project overview
A Maven + Java + Selenium WebDriver + TestNG suite that automatically tests a local HTML page containing a single-select dropdown and a multi-select list. It is designed to run headlessly so the same command works locally and in Jenkins.

## Requirements
- JDK 17 or newer (JDK 25 should also work with this Maven compiler configuration)
- Apache Maven 3.8+
- Google Chrome installed
- Internet access for the first run so Maven and Selenium Manager can download dependencies/driver if needed

## Run in VS Code (Windows)
1. Extract the ZIP to a simple path, e.g. `C:\Projects\DropdownMultiSelectTesting`.
2. Open VS Code and choose **File > Open Folder**, then select the extracted project folder.
3. Install the **Extension Pack for Java** if VS Code prompts you (optional, terminal workflow works without it).
4. Open **Terminal > New Terminal** in VS Code.
5. Verify:
   ```powershell
   java -version
   mvn -version
   ```
   If `mvn` is not recognized, install Apache Maven and add its `bin` folder to PATH, then restart VS Code.
6. Run:
   ```powershell
   mvn clean test
   ```
   Tests run headlessly. Selenium Manager normally resolves ChromeDriver automatically.
7. View reports:
   - `target/surefire-reports/index.html` (if generated by TestNG)
   - `target/surefire-reports/` for TestNG HTML/XML and text reports
   - `target/surefire-reports/TEST-*.xml` for CI/Jenkins JUnit-compatible results

To show the Chrome browser while running locally:
```powershell
mvn clean test -Dselenium.headless=false
```

## Test cases
- Dropdown option count and default selection
- Dropdown selection by visible text, value, and index
- Multi-select support and option count
- Selecting several options and verifying selected values
- Deselecting one option
- Deselecting all options

## Jenkins integration
1. Push this project to a GitHub repository.
2. Install Jenkins and ensure the Jenkins agent has Git, JDK 17+, Maven, and Google Chrome installed.
3. In Jenkins, configure JDK tool name `JDK17` and Maven tool name `Maven3` under **Manage Jenkins > Tools**, matching the Jenkinsfile.
4. Create a **Pipeline** job, choose **Pipeline script from SCM**, select Git, paste the GitHub repository URL, and set Script Path to `Jenkinsfile`.
5. Build Now. The pipeline checks out the repo, runs `mvn clean test -Dselenium.headless=true`, publishes XML test results, and archives reports.
6. For a private GitHub repository, configure Jenkins credentials and select them in the SCM settings.

If your Jenkins runs on Linux rather than Windows, replace `bat` in the Jenkinsfile with `sh 'mvn -B clean test -Dselenium.headless=true'`.

## Notes
- No test report numbers are pre-filled: use the actual output from your run in your submission.
- This suite tests the included local HTML fixture, not a production website.
